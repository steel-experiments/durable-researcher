# Modified U-Net Architecture for Instance Segmentation on Noisy Fluorescence Microscopy Images with Overlapping Cells

## 1. Architecture: Residual Attention U-Net with Boundary-Aware Heads

### 1.1 Base Architecture Choice

The proposed architecture is a **Residual Attention U-Net** that combines three key modifications to the standard U-Net encoder-decoder: **residual blocks**, **attention gates in skip connections**, and a **dual-head decoder** for simultaneous semantic and boundary prediction. This design is specifically motivated by the challenges of noisy fluorescence microscopy — low signal-to-noise ratios, variable cell morphology, and densely packed, overlapping organelles.

**Why not pure Transformer (TransUNet)?** While TransUNet's hybrid CNN-Transformer design captures long-range dependencies that standard convolutions miss [3], the quadratic computational cost of self-attention is prohibitive for high-resolution microscopy images. Instead, residual blocks with attention gates achieve a practical balance: they suppress irrelevant noisy background while remaining computationally efficient, and the residual connections prevent vanishing gradients in deep encoders [1][5].

### 1.2 Residual Blocks (Encoder & Decoder)

Standard U-Net convolutions degrade training stability in deep networks. **Residual blocks** (Conv→BN→ReLU→Conv→BN + skip→ReLU) allow the network to learn identity mappings, enabling deeper feature extraction critical for separating subtle boundary signals from fluorescence noise [2]. Each encoder level uses two residual blocks before downsampling.

### 1.3 Attention Gates in Skip Connections

Following Oktay et al. [1], **attention gates** are placed on all skip connections. Each gate takes the encoder feature map (fine-grained spatial detail) and a gating signal from the corresponding decoder level (coarse context). The gate learns to output attention coefficients ∈ [0,1] that suppress activations in irrelevant/noisy regions while propagating useful foreground features. This is critical for fluorescence microscopy where background noise and autofluorescence can dominate the signal.

### 1.4 Dual-Head Decoder

Instead of a single output, the decoder splits into two prediction heads:
- **Semantic head**: Predicts cell foreground probability (binary mask)
- **Boundary head**: Predicts cell boundary mask (thin boundaries between touching cells)

The boundary head enables marker-controlled watershed postprocessing to separate touching objects — a technique proven more effective than relying solely on distance transforms [6].

## 2. Loss Functions

### 2.1 Compound Loss: Generalized Dice Loss + Boundary Loss

Training uses a compound loss that addresses both regional overlap and precise boundary alignment:

**Generalized Dice Loss (GDL):** Handles class imbalance between small cell foreground and large background. Region-based, insensitive to object size.

**Boundary Loss (Kervadec et al., MIDL 2019, MedIA 2021) [6]:** Computes a boundary-level loss using a pre-computed signed distance map from ground-truth boundaries. The distance map is signed (negative inside objects, positive outside), so the loss penalizes predictions whose boundaries deviate from ground truth. It operates as a pixel-wise multiplication between softmax outputs and the distance map.

```
Total Loss = GDL + α · BoundaryLoss    (α = 0.01)
```

The boundary loss is weighted lightly because it provides a fine-grained gradient signal complementing the regional Dice loss. This combination was shown to be highly effective for unbalanced segmentation problems [6].

### 2.2 Boundary-Aware Touching Loss

For the boundary prediction head, a weighted binary cross-entropy is used with higher weight on boundary pixels (typically 5–10×) to counteract their sparsity relative to interior/background pixels.

## 3. Postprocessing: Separating Touching Objects

### 3.1 Marker-Controlled Watershed

After inference, the two output heads are combined to separate touching cells:

1. **Threshold** the semantic probability map at 0.5 to get the foreground mask.
2. **Compute distance transform** of the foreground mask (`scipy.ndimage.distance_transform_edt`).
3. **Find markers**: Local maxima of the distance transform (or thresholded peaks) serve as seeds — one per cell instance.
4. **Watershed**: Apply marker-controlled watershed using the *negative distance map*, with the predicted *boundary mask as a barrier* that prevents merging across cell boundaries. This is the critical step: the boundary head provides learned separation cues where distance-map-based heuristics fail.

### 3.2 Small Object Removal

Post-watershed, connected components smaller than a minimum area threshold (e.g., 50 pixels) are removed to eliminate noise-driven artifacts.

### 4.1 Residual Attention Block

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    """Residual block with two 3x3 convolutions and skip connection."""
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.skip = (nn.Conv2d(in_channels, out_channels, 1)
                     if in_channels != out_channels else nn.Identity())
        self.relu = nn.ReLU(inplace=True)

    def forward(self, x):
        residual = self.skip(x)
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return self.relu(out + residual)


class AttentionGate(nn.Module):
    """Attention gate for skip connections (Oktay et al., 2018)."""
    def __init__(self, F_g, F_l, F_int):
        super().__init__()
        self.W_g = nn.Sequential(
            nn.Conv2d(F_g, F_int, 1, bias=False),
            nn.BatchNorm2d(F_int)
        )
        self.W_x = nn.Sequential(
            nn.Conv2d(F_l, F_int, 1, bias=False),
            nn.BatchNorm2d(F_int)
        )
        self.psi = nn.Sequential(
            nn.Conv2d(F_int, 1, 1, bias=False),
            nn.BatchNorm2d(1),
            nn.Sigmoid()
        )
        self.relu = nn.ReLU(inplace=True)

    def forward(self, g, x):
        g1 = self.W_g(g)
        x1 = self.W_x(x)
        psi = self.relu(g1 + x1)
        psi = self.psi(psi)
        return x * psi  # Attention-weighted skip connection
```

### 4.2 Full Model

```python
class ResidualAttentionUNet(nn.Module):
    def __init__(self, in_channels=1, base_filters=64):
        super().__init__()
        # Encoder
        self.enc1 = nn.Sequential(ResidualBlock(in_channels, base_filters),
                                   ResidualBlock(base_filters, base_filters))
        self.enc2 = nn.Sequential(ResidualBlock(base_filters, base_filters*2),
                                   ResidualBlock(base_filters*2, base_filters*2))
        self.enc3 = nn.Sequential(ResidualBlock(base_filters*2, base_filters*4),
                                   ResidualBlock(base_filters*4, base_filters*4))
        self.pool = nn.MaxPool2d(2)

        # Bottleneck
        self.bottleneck = ResidualBlock(base_filters*4, base_filters*8)

        # Decoder
        self.up3 = nn.ConvTranspose2d(base_filters*8, base_filters*4, 2, stride=2)
        self.dec3 = ResidualBlock(base_filters*8, base_filters*4)
        self.up2 = nn.ConvTranspose2d(base_filters*4, base_filters*2, 2, stride=2)
        self.dec2 = ResidualBlock(base_filters*4, base_filters*2)
        self.up1 = nn.ConvTranspose2d(base_filters*2, base_filters, 2, stride=2)
        self.dec1 = ResidualBlock(base_filters*2, base_filters)

        # Attention gates
        self.ag3 = AttentionGate(base_filters*4, base_filters*4, base_filters*2)
        self.ag2 = AttentionGate(base_filters*2, base_filters*2, base_filters)
        self.ag1 = AttentionGate(base_filters, base_filters, base_filters // 2)

        # Dual prediction heads
        self.semantic_head = nn.Conv2d(base_filters, 1, 1)  # Cell probability
        self.boundary_head = nn.Conv2d(base_filters, 1, 1)  # Cell boundaries

    def forward(self, x):
        # Encoder
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))

        # Bottleneck
        b = self.bottleneck(self.pool(e3))

        # Decoder with attention gates
        d3 = self.up3(b)
        e3_att = self.ag3(g=d3, x=e3)
        d3 = self.dec3(torch.cat([d3, e3_att], dim=1))

        d2 = self.up2(d3)
        e2_att = self.ag2(g=d2, x=e2)
        d2 = self.dec2(torch.cat([d2, e2_att], dim=1))

        d1 = self.up1(d2)
        e1_att = self.ag1(g=d1, x=e1)
        d1 = self.dec1(torch.cat([d1, e1_att], dim=1))

        return torch.sigmoid(self.semantic_head(d1)), \
               torch.sigmoid(self.boundary_head(d1))
```

### 4.3 Loss Functions

```python
class BoundaryLoss(nn.Module):
    """Boundary loss using pre-computed signed distance maps.
    Reference: Kervadec et al., MIDL 2019 / MedIA 2021."""
    def __init__(self):
        super().__init__()

    def forward(self, probs, dist_maps):
        # probs: (B, 1, H, W) - predicted foreground probability
        # dist_maps: (B, 1, H, W) - signed distance map (neg inside, pos outside)
        return (probs * dist_maps).mean()


class DiceLoss(nn.Module):
    def __init__(self, smooth=1e-6):
        super().__init__()
        self.smooth = smooth

    def forward(self, preds, targets):
        intersection = (preds * targets).sum(dim=(2, 3))
        union = preds.sum(dim=(2, 3)) + targets.sum(dim=(2, 3))
        dice = (2. * intersection + self.smooth) / (union + self.smooth)
        return 1. - dice.mean()


class WeightedBCELoss(nn.Module):
    """Weighted BCE for sparse boundary pixels."""
    def __init__(self, boundary_weight=5.0):
        super().__init__()
        self.boundary_weight = boundary_weight

    def forward(self, preds, targets):
        bce = nn.functional.binary_cross_entropy(preds, targets, reduction='none')
        weights = 1.0 + (self.boundary_weight - 1.0) * targets
        return (weights * bce).mean()


class CompoundLoss(nn.Module):
    """Full training loss: GDL + α·BoundaryLoss + β·WeightedBCE(boundary)."""
    def __init__(self, alpha=0.01, beta=1.0, boundary_weight=5.0):
        super().__init__()
        self.dice = DiceLoss()
        self.boundary = BoundaryLoss()
        self.weighted_bce = WeightedBCELoss(boundary_weight)
        self.alpha = alpha
        self.beta = beta

    def forward(self, sem_pred, bnd_pred, sem_target, bnd_target, dist_maps):
        loss_dice = self.dice(sem_pred, sem_target)
        loss_boundary = self.boundary(sem_pred, dist_maps)
        loss_bnd_bce = self.weighted_bce(bnd_pred, bnd_target)
        return loss_dice + self.alpha * loss_boundary + self.beta * loss_bnd_bce
```

### 4.4 Watershed Postprocessing

```python
import numpy as np
from scipy.ndimage import distance_transform_edt, label
from skimage.segmentation import watershed
from skimage.feature import peak_local_max

def separate_instances(semantic_mask, boundary_mask, min_cell_area=50):
    """Separate touching cells using marker-controlled watershed.
    
    Args:
        semantic_mask: (H, W) binary foreground mask
        boundary_mask: (H, W) predicted boundary probability map
        min_cell_area: minimum area in pixels for a valid cell
    Returns:
        instance_map: (H, W) integer label map
    """
    # Compute distance transform of the foreground
    dist = distance_transform_edt(semantic_mask)
    
    # Suppress boundaries: zero out distance near predicted boundaries
    boundary_barrier = boundary_mask > 0.5
    dist[boundary_barrier] = 0
    
    # Find markers: local maxima of the modified distance map
    coords = peak_local_max(dist, min_distance=5, labels=semantic_mask)
    markers = np.zeros_like(dist, dtype=np.int32)
    markers[tuple(coords.T)] = np.arange(1, len(coords) + 1)
    
    # Watershed on negative distance map
    instance_map = watershed(-dist, markers, mask=semantic_mask)
    
    # Remove small objects
    for label_id in np.unique(instance_map):
        if label_id == 0:
            continue
        if np.sum(instance_map == label_id) < min_cell_area:
            instance_map[instance_map == label_id] = 0
    
    return instance_map
```

### 5.1 Key Comparative Insights

**vs. Cellpose:** Cellpose's gradient field approach is elegant and achieves strong performance on moderately dense images. However, on highly confluent images, its generalist model achieves only AP 13.9% [4]. Our architecture explicitly predicts inter-cell boundaries, providing direct cues for separation rather than relying on vector field convergence, which can be ambiguous when gradients from adjacent cells cancel near touching boundaries.

**vs. StarDist:** StarDist's star-convex representation is highly effective for roughly circular nuclei [2], but the radial distance parametrization limits accuracy for elongated or highly irregular organelles (e.g., mitochondria, neurites). Our pixel-wise approach imposes no shape prior, making it more flexible for diverse morphologies.

**vs. Mask R-CNN:** Mask R-CNN's bounding-box-first paradigm is ill-suited for dense fluorescence microscopy. The anchor-based region proposal network struggles when cells overlap extensively — LIVECell benchmarks show anchor-based models fail above ~1,403 objects per image [4]. Our fully convolutional approach processes the entire image at once, avoiding this bottleneck entirely.

## 6. Training Recommendations

- **Data augmentation**: Random rotations, elastic deformations, Gaussian noise injection (σ=10–30), intensity scaling, and flip augmentations are essential to simulate microscopy variability.
- **Pre-computed distance maps**: The signed distance maps for boundary loss should be pre-computed per ground-truth mask at the dataloader level using `scipy.ndimage.distance_transform_edt` [6].
- **Learning rate**: 1e-3 with cosine annealing schedule; batch size 4–8 depending on GPU memory.
- **Loss weighting**: α=0.01 for boundary loss relative to Dice loss [6]; β=1.0 for boundary BCE.
