# A Biologically Plausible Network Integrating Engrams and Predictive Coding for Classification

## Executive Summary

This report proposes a unified neural architecture—the **Predictive Engram Network (PEN)**—that integrates two cornerstone neuroscience frameworks: **engrams** (sparse, persistent memory traces) and **predictive coding** (hierarchical error minimization). The model is grounded in the Rao-Ballard hierarchical predictive coding framework, hippocampal pattern separation/completion circuitry, and Hebbian memory-augmented learning. It performs classification entirely through local, biologically plausible computations—no global backpropagation required—by matching sensory inputs to stored engram attractors via free-energy minimization.

---

## 1. Neuroscientific Foundations

### 1.1 Engrams: The Physical Substrate of Memory

The concept of the "engram"—a physical neural change encoding a memory—was introduced by Richard Semon in 1904. Modern neuroscience has established that engrams are carried by sparse, distributed cell assemblies, primarily localized in the hippocampus and ventromedial prefrontal cortex (vmPFC) [1]. Key computational properties include:

- **Sparse Distributed Representations (SDRs):** Only a small percentage of neurons fire for any given stimulus, ensuring high capacity and low interference between stored memories [1][4].
- **Pattern Separation:** The dentate gyrus (DG) of the hippocampus transforms similar inputs into distinct, non-overlapping sparse codes, preventing catastrophic interference. This is facilitated by diluted connectivity and disynaptic inhibition [4][5].
- **Pattern Completion:** The CA3 hippocampal subregion operates as a recurrent attractor network (following Hopfield dynamics), reconstructing full stored patterns from partial or degraded cues via long-term potentiation (LTP) [5].
- **Semantization:** Memories undergo a representational shift over time—from perceptual/visual formats to semantic/conceptual formats—during consolidation, tracked via Representational Similarity Analysis (RSA) and deep neural network models [1].

### 1.2 Predictive Coding: The Brain as an Inference Machine

Predictive coding, formalized by Rao & Ballard (1999), proposes that the brain continuously generates top-down predictions of sensory input and updates internal models based on bottom-up prediction errors [2][3][6]. The framework operates through:

- **Hierarchical Generative Models:** Each layer maintains representation units that generate top-down predictions for the layer below.
- **Error Units:** Dedicated neuronal populations compute the mismatch between actual activity and predicted activity.
- **Precision Weighting:** Prediction errors are scaled by precision (inverse variance), modulating how strongly bottom-up mismatches influence higher-level updates [2].
- **Inference Learning (IL):** An alternative to backpropagation that uses iterative, local state updates to minimize variational free energy—aligning closely with cortical processing [6].

## 2. Proposed Architecture: The Predictive Engram Network (PEN)

### 2.1 High-Level Design

The PEN architecture consists of **three functionally specialized modules** arranged in a hierarchy, each directly analogous to a known brain region:

| Module | Brain Analog | Function |
|--------|-------------|----------|
| **Sensory-Predictive Hierarchy** | Neocortex (visual/auditory areas) | Multi-layer predictive coding; extracts features and computes prediction errors |
| **Pattern Separation Module** | Dentate Gyrus (DG) | Orthogonalizes prediction errors into sparse, non-overlapping engram codes |
| **Engram Attractor Module** | CA3 + Entorhinal Cortex | Stores class engrams as recurrent attractor states; performs pattern completion for classification |

### 2.2 Module 1: Sensory-Predictive Hierarchy

This module implements a standard Rao-Ballard predictive coding hierarchy with $L$ layers [2][6]:

**Representation units** $r^{(l)} \in \mathbb{R}^{n_l}$ at each layer generate top-down predictions:
$$r^{(l-1)}_{pred} = W^{(l)\top} r^{(l)}$$

**Error units** $e^{(l)}$ compute bottom-up prediction errors:
$$e^{(l)} = r^{(l-1)} - W^{(l)\top} r^{(l)}$$

**State updates** follow local dynamics (no global gradient):
$$r^{(l)} \leftarrow r^{(l)} + \eta \left[ W^{(l)} e^{(l)} - W^{(l+1)\top} e^{(l+1)} \right]$$

The sensory input is clamped to the lowest layer: $r^{(0)} \equiv x$. The hierarchy minimizes variational free energy:
$$F = \sum_{l=1}^{L} \frac{1}{2} \| e^{(l)} \|^2_{\Sigma^{(l)}} + \frac{1}{2} \| r^{(L)} \|^2_{\Pi^{(L)}}$$

where $\Sigma^{(l)} = \sigma_l^2 I$ is the noise covariance and $\Pi^{(L)} = \lambda^2 I$ is the prior precision at the top layer. After convergence, the prediction-error vectors $e^{(1)}, \ldots, e^{(L)}$ are passed to Module 2.

### 2.3 Module 2: Pattern Separation (DG Analog)

This module receives the prediction errors from the hierarchy and orthogonalizes them into sparse engram codes, mimicking dentate gyrus function [4][5]:

$$s = \text{Sparsify}\left(\tanh\left(W_{sep} \cdot [e^{(1)}; e^{(2)}; \ldots; e^{(L)}] + b_{sep}\right), k\right)$$

where $\text{Sparsify}(\cdot, k)$ retains only the top-$k$ activations and zeros the rest, enforcing extreme sparsity (typically 2–5% active units). The weight matrix $W_{sep}$ is initialized with diluted (sparse) connectivity to ensure pattern separation—mathematically constrained by the joint incoherence condition $\kappa < \frac{1}{2}$ [4].

**Key property:** Similar inputs produce similar prediction errors in the hierarchy, but the sparse non-linear projection ensures the resulting engram codes $s$ are highly dissimilar, preventing interference between stored class memories.

### 2.4 Module 3: Engram Attractor (CA3 Analog)

This module stores and retrieves class engrams via recurrent attractor dynamics, modeled as a Modern Hopfield Network (MHN) [4]:

**Storage:** For each class $c$, an engram prototype $\xi_c$ is formed as the sparse code $s$ produced by the dominant input pattern for that class. Synaptic weights store these via a Hebbian outer-product rule:
$$M = \sum_{c=1}^{C} \xi_c \xi_c^\top$$

**Retrieval (Pattern Completion):** Given a novel sparse code $s$ from Module 2, the attractor dynamics iterate:
$$s^{(k+1)} = \sum_{c=1}^{C} \text{softmax}_c\left[\beta \cdot \xi_c^\top s^{(k)}\right] \cdot \xi_c$$

where $\beta$ is an inverse temperature parameter controlling attractor sharpness. The network converges to the stored engram $\xi_{c^*}$ most similar to the input cue.

**Classification Readout:** The class label is:
$$\hat{y} = \arg\max_c \left[ \xi_c^\top s^{(\infty)} \right]$$

### 2.5 Top-Down Feedback Loop (Hippocampal-Cortical Dialogue)

Critically, the settled engram state $\xi_{c^*}$ generates a **top-down prediction** that propagates back to the sensory hierarchy via generative feedback weights:
$$r^{(L)}_{feedback} = W_{feedback} \cdot \xi_{c^*}$$

This implements the predictive coding loop: the engram acts as the brain's "hypothesis" about what is being perceived, and the hierarchy tests this hypothesis against incoming sensory data. This bidirectional flow mirrors the entorhinal-hippocampal circuit [4][5].

## 3. Learning Rules

### 3.1 Synaptic Weight Updates in the Hierarchy

All weights in the sensory-predictive hierarchy use **local Hebbian adaptation** between error units and representation units [2]:
$$\Delta W^{(l)} = \eta_w \cdot e^{(l)} \cdot (r^{(l)})^\top$$

This is biologically plausible: it requires only information available at the synapse (pre-synaptic activity $r^{(l)}$ and post-synaptic error $e^{(l)}$).

### 3.2 Engram Formation via Fast Hebbian Plasticity

The separation weights $W_{sep}$ and memory matrix $M$ use a **dual-timescale learning rule** [7][8]:

- **Fast Hebbian trace** (analogous to short-term memory):
$$H_t = (1 - \eta) H_{t-1} + \eta (a_t \otimes z_t)$$

- **Slow consolidation** into the persistent memory bank $M$ via gradient-free local updates during offline "replay" periods, mimicking hippocampal replay during sharp-wave ripples.

### 3.3 Attention-Based Memory Recall

Memory retrieval uses **cosine similarity with sparse softmax attention** [7][8]:
$$\alpha_c = \frac{\exp(\beta \cdot \cos(s, \xi_c))}{\sum_{c'} \exp(\beta \cdot \cos(s, \xi_{c'}))}$$

with sparsity constraints ensuring only a small subset of engram neurons activate per input, matching biological observations of sparse engram reactivation [1].

## 4. Classification Procedure

### 4.1 Training Phase

1. **Forward pass:** Present labeled input $x$; clamp to lowest hierarchical layer.
2. **Inference:** Iteratively update all $r^{(l)}$ via local prediction-error dynamics until convergence.
3. **Separation:** Compute sparse code $s$ from prediction errors via the DG module.
4. **Engram binding:** For inputs of class $c$, update the corresponding engram $\xi_c$ using Hebbian outer-product learning.
5. **Weight adaptation:** Update all $W^{(l)}$ via local Hebbian rules.
6. **Offline replay:** Periodically replay stored engrams to consolidate into slow weights (preventing catastrophic forgetting).

### 4.2 Inference (Classification) Phase

1. Present unlabeled input $x$; run hierarchical inference to convergence.
2. Compute sparse prediction-error code $s$ via DG separation.
3. Run CA3 attractor dynamics until convergence to a stored engram $\xi_{c^*}$.
4. Read out class: $\hat{y} = c^*$.
5. Optionally, propagate top-down prediction from $\xi_{c^*}$ back down the hierarchy for iterative refinement.

## 5. Biological Plausibility Assessment

| Design Principle | Biological Plausibility | Justification |
|---|---|---|
| **No backpropagation** | ✅ High | Inference Learning uses only local, feedforward/feedback messages [6] |
| **Sparse coding** | ✅ High | Matches observed <5% activation rates in hippocampal engrams [1][5] |
| **Hebbian learning** | ✅ High | Outer-product rule mirrors spike-timing-dependent plasticity [7][8] |
| **Hierarchical organization** | ✅ High | Mirrors laminar cortical circuitry with superficial (error) and deep (representation) layers [2][6] |
| **Pattern separation / completion** | ✅ High | Directly modeled on DG→CA3 circuitry [4][5] |
| **Dual-timescale memory** | ✅ High | Fast Hebbian trace + slow consolidation mimics systems consolidation [1][8] |
| **Top-down predictions** | ✅ High | Matches corticothalamic and hippocampal-cortical feedback pathways [2][4] |
| **Attention-based recall** | ⚠️ Moderate | Softmax attention is a simplified abstraction of neuromodulatory gain control [7] |

## 6. Relation to Existing Computational Frameworks

The proposed PEN architecture draws from and extends several existing models:

- **Rao-Ballard Predictive Coding (1999):** Provides the hierarchical error-computation backbone [2].
- **Modern Hopfield Networks:** Supply the dense associative memory (attractor) dynamics for engram storage [4].
- **Hebbian Memory-Augmented Recurrent Networks (HMARNs):** Demonstrate that fast Hebbian plasticity integrated with slow gradient-based learning achieves competitive one-shot classification (99.4% on 5-way 1-shot Omniglot) [8].
- **Predictive Coding Networks (PCNs) with Inference Learning:** Establish that hierarchical predictive coding with local learning can match or exceed backpropagation in classification tasks when sufficiently parallelized [6].
- **VAE + MHN Hybrid Architectures:** Propose combining variational generative models with Hopfield memory for classification [4].

The PEN model is novel in **unifying all three subsystems** (predictive hierarchy, sparse separation, attractor memory) into a single end-to-end trainable architecture with strictly local learning rules.

## 7. Predicted Performance Characteristics

Based on the performance of constituent components in the literature:

- **Classification accuracy:** PCNs achieve competitive results on MNIST, CIFAR-10, and ImageNet subsets using inference learning [6]. The addition of explicit engram memory should improve few-shot and continual learning scenarios.
- **Continual learning:** The sparse pattern separation mechanism should significantly reduce catastrophic interference, as orthogonalized engram codes prevent overlap between classes [4][5].
- **One-shot learning:** The fast Hebbian binding in the engram module enables rapid encoding of new classes from single examples, as demonstrated in HMARN architectures (99.4% on Omniglot) [8].
- **Computational cost:** Inference Learning was historically more expensive than backpropagation, but recent work shows it can be more efficient with parallelization [6].

## Uncertainty & Gaps

- **Empirical validation:** The proposed PEN architecture has not been empirically tested as a unified system. Performance estimates are extrapolated from individual component benchmarks.
- **Precision weighting mechanism:** How precision (attention to prediction errors) should be dynamically regulated across the hierarchy during classification remains an open design question.
- **Scalability:** While PCNs have been demonstrated on standard benchmarks, integrating the engram attractor module at scale (e.g., ImageNet with 1000 classes) introduces memory capacity constraints in the Hopfield layer that require further analysis.
- **Offline replay scheduling:** The biological mechanism of sharp-wave ripple replay is well-established, but the optimal computational scheduling for the consolidation step in PEN remains to be determined.
- **Conflict in learning rules:** Some sources propose purely Hebbian learning [2][8], while others suggest hybrid Hebbian + gradient-free predictive error minimization. The optimal balance for classification accuracy vs. biological fidelity requires empirical investigation.
